UTILS

--------------------------------------------------
1. LAYOUT & ORGANIZAÇÃO (Flexbox & Grid)
--------------------------------------------------

* display: flex
  Resumo: Transforma a caixa num contentor flexível.
  Detalhe: Serve para alinhar os elementos facilmente. Vai meter os elementos todos na horizontal por defeito, enquanto display: inline/block os meteria uns em cima dos outros.

* display: grid
  Resumo: Cria uma grelha de linhas e colunas.
  Detalhe: Perfeito para tabelas ou galerias de cartões. Usámos muito no "grid-template-columns: repeat(...)" para os cartões de produtos.

* flex-direction: column
  Resumo: Organiza na vertical.
  Detalhe: Todos os elementos que metermos dentro do contentor vão ser organizados em coluna, ou seja "um em cima do outro".

* flex-wrap: wrap
  Resumo: Previne que os itens encolham até desaparecer.
  Detalhe: Isto é essencial para o site funcionar bem no telemóvel! Diz ao browser: "Se não houver espaço suficiente no ecrã para os itens ficarem lado a lado, empurra os que não cabem para a linha de baixo".

* gap: 20px
  Resumo: Cria consistência no espaçamento.
  Detalhe: Cria um espaço vazio (um "buraco") exato entre cada cartão ou elemento. É muito mais limpo do que usar margins de forma isolada nos elementos.

* align-items: center
  Resumo: Centra verticalmente.
  Detalhe: Movimenta os elementos no eixo oposto ao do contentor para ficarem perfeitamente no meio.

* justify-content: center / space-between
  Resumo: Centra ou afasta horizontalmente.
  Detalhe: "center" junta tudo no meio. O "space-between" pega no primeiro elemento e encosta-o à esquerda, e pega no último e encosta-o à direita.


--------------------------------------------------
2. ESPAÇAMENTO E TAMANHOS (Margens, Estofos, Larguras)
--------------------------------------------------

* margin-top: 30px (e margin-bottom / left / right)
  Resumo: Empurra os elementos de fora.
  Detalhe: Dá um empurrãozinho, criando um espaço de proteção externo entre a secção atual e o elemento que está à sua beira.

* padding: 12px 24px
  Resumo: Cria estofo ou espaço por dentro.
  Detalhe: Não afasta os vizinhos, mas enche o interior. A ordem "12px 24px" significa: 12px em Cima/Baixo e 24px à Esquerda/Direita. Muito usado em botões.

* width: 100% / height: 100% (ou 100vh)
  Resumo: Força o tamanho do elemento.
  Detalhe: Valores em % fazem a caixa esticar-se baseada no espaço livre. O "100vh" (Viewport Height) significa "ocupa 100% da altura exata do ecrã do browser".

* resize: vertical
  Resumo: Controla o arrasto das textareas.
  Detalhe: Usámos na caixa de "Notas" do Checkout para permitir que o cliente aumente a caixa apenas para baixo, impedindo que estrague o layout esticando para os lados.

* max-width: 1200px
  Resumo: Limita o crescimento em ecrãs muito largos.
  Detalhe: Se alguém aceder num monitor de 32 polegadas, os conteúdos não vão esticar infinitamente até ficar feio. Param nos 1200 píxeis.


--------------------------------------------------
3. POSICIONAMENTO (Position e Z-Index)
--------------------------------------------------

* position: relative / absolute / fixed / sticky
  Resumo: Controla onde a caixa fica na página.
  Detalhe: O "fixed" prende o elemento ao ecrã (ex: Sidebar azul). O "absolute" solta o elemento para poderes colá-lo noutro lugar qualquer através das regras "top, right, bottom, left". O "relative" serve de ancora para prender os filhos que tenham position absolute.

* z-index: 100
  Resumo: Decide quem fica à frente (numérico).
  Detalhe: Se duas caixas se atropelarem umas por cima das outras, atiras a regra z-index. Quanto maior o número, mais para a frente a caixa fica.

* top / right / bottom / left: 2rem
  Resumo: Move a caixa num dos "axes".
  Detalhe: Usámos com o position:absolute para grudar o botão de "Criar Conta" mesmo no cantinho direito no topo.


--------------------------------------------------
4. ESTÉTICAS, EFEITOS E VISUAIS
--------------------------------------------------

* color / background
  Resumo: Pinta o texto ou o fundo.
  Detalhe: "color" muda SEMPRE APENAS E SÓ a cor da letra (texto). O "background" pinta a parede do fundo da caixa.

* background: linear-gradient(135deg, ...)
  Resumo: Efeito degradê de 2 ou mais cores.
  Detalhe: Torna sites modernos em vez de estarem chapados com cor sólida. Vai transitando as cores.

* background-image / background-size / background-position
  Resumo: Fundo de fotografia.
  Detalhe: O url('/imagem') define-a, o "background-size: cover" impõe que a foto tem de ocupar tudo sem se deformar, e "position: center" é a foquilha!

* border: 1px solid #ddd
  Resumo: Risco nas bordas.
  Detalhe: 3 propriedades importantes num só sítio: tamanho do risco (1px) + o padrão do risco (solid = normal contínuo) + a cor (#ddd).

* outline: none
  Resumo: Sem riscas horriveis ao focar as boxes.
  Detalhe: Impede o google de meter aquela linha escura horrível no input a dizer "OLHA ESTAS A ESCREVER ESTÁ AQUI!". Remove o traçado por defeito sempre.

* border-radius: 8px / 12px / 50%
  Resumo: Arredonda os cantos das caixas.
  Detalhe: Dá um aspeto suave. Se usares 50%, a caixa curva-se até ser um círculo perfeito (usámos no logotipo do "Meu Perfil").

* box-shadow: 0 2px 8px rgba(0,0,0,0.08)
  Resumo: Aplica sombras suaves à volta.
  Detalhe: Ajuda a dar profundidade de destacar cartões (efeito "flutuante").

* transition: transform 0.2s
  Resumo: Câmera lenta das mudanças de estilo.
  Detalhe: Sem isto, quando um botao muda de cor ou cresce parecia algo bué rude ("pum-pum"). Mete delay para a malta notar "pfiunn, nice!".

* transform: translateY(-4px)
  Resumo: Manipulação de posições em movimento.
  Detalhe: "transforma", levanta e tira para cima do ar. Quando passo rato no meu button, de repente saltita 4 unidades (pixels).  

* opacity: 0.8
  Resumo: Nível do 'Fantasma'
  Detalhe: Escala de 0 até 1. 0 tás fantasma não se vê, 1 é um tijolo super visível. 0.8 não está apagado, mas é "dim".


--------------------------------------------------
5. TIPOGRAFIA E TEXTO
--------------------------------------------------

* font-weight: 600 / 700 / 800
  Resumo: Engrossa a letra.
  Detalhe: Funciona aos níveis. 400 é o texto normal, 600 é semi-negrito, 700 é negrito forte, 800 é super grosso (usámos nos preços).

* text-decoration: none
  Resumo: Limpa os riscos do texto.
  Detalhe: Usámos para remover aqueles sublinhados horríveis e azuis que os links (tags <a>) ganham por defeito.

* accent-color: #1a237e
  Resumo: Muda a cor das bolinhas nativas.
  Detalhe: Usámos no Checkout (<input type="radio">). Em vez daquela bolinha azul padrão escassa da Microsoft/Apple para selecionar a opção, pintámos com o nosso azul vibrante corporativo!

* text-align: right / center
  Resumo: Alinha o texto na sua própria caixa.
  Detalhe: Excelente para tabelas. Colocámos os preços com text-align: right para as vírgulas dos preços alinharem todas umas por baixo das outras no Carrinho.

* letter-spacing / line-height
  Resumo: "Mexe/Aperta" e afasta as letras, respetivamente.
  Detalhe: Diminui a chatice do espaçamento do texto ou das linhas serem enormes se os cartões estiverem com os titulos mto grossos.

--------------------------------------------------
6. IMAGENS
--------------------------------------------------
* object-fit: cover
  Resumo: Faz a imagem preencher o espaço sem distorcer.
  Detalhe: Essencial para imagens de produtos! Garante que a foto ocupa a caixa toda (100% largura e altura) cortando os excessos em vez de ficar "esmagada".


--------------------------------------------------
7. TAGS HTML USADAS NO PROJETO
--------------------------------------------------

* <div>
  Resumo: A "caixa" universal.
  Detalhe: É um contentor genérico. Não tem nenhum aspeto visual sozinho, mas serve para embrulhar outras coisas (textos, botões, etc.) para que possas aplicar estilos CSS em grupo.

* <form>
  Resumo: Formulário de envio de dados.
  Detalhe: Agrupa campos de preenchimento. Diz ao browser para agarrar nos dados preenchidos ali dentro e enviá-los para o servidor (backend) ao clicar no botão de submter (usando GET para pesquisas ou POST para gravar coisas).

* <label>
  Resumo: O título do campo.
  Detalhe: É o textinho explicativo que metes junto de um campo de preenchimento (ex: "Pesquisar") para o cliente saber o que ali tem de fazer.

* <input>
  Resumo: Onde o cliente escreve/interage.
  Detalhe: Usámos com type="text" (caixas de pesquisa/nomes), type="hidden" (esconder dados como IDs de produtos que só interessam ao servidor), ou type="radio" (as bolinhas de seleção do método de entrega).

* <select> e <option>
  Resumo: Menu Dropdown (lista pendente).
  Detalhe: O <select> é o esqueleto caixa principal, e cada <option> é uma das escolhas disponíveis lá para dentro (ex: Filtro de Categorias).

* <button>
  Resumo: Botão clicável.
  Detalhe: Serve para realizar ações. Se estiver dentro de um "form" e tiver type="submit", executa logo o envio dos dados.

* <a>
  Resumo: O identificador de links.
  Detalhe: Transforma texto ou outros elementos num link que leva o utilizador para outra página (propriedade "href" define o destino). Usado no menu lateral.

* <span>
  Resumo: A "caixa" invisível para palavras justas.
  Detalhe: Igual a uma <div> mas é "em linha" (inline). Serve para selecionares e decorares só uma palavrinha no meio de uma frase sem atirar todo o resto do texto para uma quebra de linha.

* <img>
  Resumo: Insere uma fotografia.
  Detalhe: Carrega uma imagem pelo URL do "src" (source) e usa o "alt" para colocar uma descrição alternativa caso a imagem falhe a carregar ou para invisuais através dos leitores de ecrã.

* <h1> / <h3> / <p>
  Resumo: A hierarquia do texto.
  Detalhe: <h1> é o Título gigante principal da página inteira (Ideal ter SÓ UM), <h3> são os subtítulos médios (ex: nomes de produtos nos cartões da loja), e <p> é texto banal de parágrafo de leitura corrida.

--------------------------------------------------
7. TAG HTML TABLE
--------------------------------------------------

* <table>
  Resumo: A caixa principal da Tabela.
  Detalhe: Serve como o "saco" gigante que vai agrupar e forçar tudo o que meterdes lá dentro a comportar-se com linhas e colunas rígidas (estilo folha de Excel).

* <thead> e <tbody>
  Resumo: As zonas organizacionais da Tabela.
  Detalhe: Super úteis. O <thead> (Table Head) agrupa apenas os títulos das colunas lá em cima. O <tbody> (Table Body) agrupa as linhas do conteúdo real. Ajuda o código a separar os títulos dos produtos.

* <tr>
  Resumo: A linha que corta na horizontal.
  Detalhe: Vem de "Table Row" (Linha da tabela). Sempre que abres um <tr>, o ecrã percebe que estás a criar uma nova fatia horizontal na tabela para lá enfiares dados.

* <th>
  Resumo: O bloco de Título.
  Detalhe: Vem de "Table Header" (Cabeçalho da tabela). Usado estritamente na 1ª linha (no thead) para meter as palavras grossas que dizem ao utilizador o que é cada coluna (ex: "Preço", "Stock").

* <td>
  Resumo: O bloco de Dados normal.
  Detalhe: Vem de "Table Data" (Dados da tabela). Usado dentro do <tbody>. Se a linha de cima tem 5 <th>, a tua linha de baixo tem de ter 5 <td> certinhos para os dados não ficarem tortos ou descarrilados.

--------------------------------------------------
8. O CICLO FOREACH NO EJS E OS SEUS PARÂMETROS
--------------------------------------------------

* products.forEach(function(a, b, c) { ... })
  Resumo: O iterador rigoroso de listas.
  Detalhe: O forEach é uma função cega do JavaScript que pega numa lista e despeja o seu conteúdo vezes sem conta. O grande segredo está NAS POSIÇÕES e não nos nomes das variáveis que inventamos!

  - A Primeira Cadeira (a): 
    Seja qual for a palavra que escrevas na 1ª posição (ex: product, item, batata), o motor do forEach vai atirar o VALOR / OBJETO real para dentro dessa variável. 
  
  - A Segunda Cadeira (b):
    A 2ª posição está reservada nativamente para ser sempre o CONTADOR MATEMÁTICO do ciclo (0, 1, 2, 3...). Seja "index" ou "bolacha", essa variável vai receber sempre e apenas posições numéricas.

  - A Terceira Cadeira (c):
    Existe uma 3ª posição fantasma! Se adiciones uma terceira palavra (ex: function(product, index, lista)), essa posição devolverá sempre o Array Intacto (O "Saco de Compras" original inteiro).
